# 📚 Knowledge Base Rules

이 디렉토리는 시스템 전체의 지식 결정화(Crystallized Knowledge)와 자가 진화(Self-Evolution)를 위한 규칙, 성공 패턴, 피드백 로그가 저장되는 중앙 리포지토리입니다.

## [핵심 임무]
- 에이전트 간 피드백 저장: 기자의 데스크 승인 프로세스를 통과한 기사의 성공 패턴, 수정 내역, 반려 사유 등을 체계적으로 기록합니다.
- 매니저 에이전트의 룰셋 참조: Chief Manager Agent는 이 디렉토리의 데이터를 분석하여 전체 워크플로우를 개선하고 하위 에이전트들의 프롬프트를 동적으로 업데이트합니다.
- 보안 위협 및 에러 로그: 보안 에이전트가 탐지한 환각(Hallucination) 패턴, API 통신 에러 등의 시스템 로그를 보관하여 재발을 방지하는 룰셋 생성의 근거로 사용합니다.
